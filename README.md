Instrucciones para ejecutar el programa:
1. make
2. make test FILE=test.micro
3. make clean

Archivos de prueba:

Estos se encuentran en la misma carpeta. Los casos llamados test seguidos por algún número, son propios. Están diseñados para que algunos tiren diversos errores para poner a prueba el control del programa.

Aquellos archivos de prueba cuyo nombre no comparte este formato, corresponden a casos de prueba provistos por otros grupos como fue sugerido.
